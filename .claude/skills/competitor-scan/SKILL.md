# competitor-scan

Вход: ссылка на сайт конкурента. Выход: запись о нём в разделе «Разборы по ссылкам» в конце `_docs/competitors.md`. Остальное содержимое файла не трогать.

## Шаги

1. **Открой продающие страницы.** Главная, тарифы, возможности, «для кого». Ссылки на них бери с главной. Блог и документацию не открывай. Только публичные страницы: не регистрируйся и не заходи за логин.
2. **Вычитай всё нужное для записи.** Каждый факт бери только со страниц сайта конкурента. Ничего из памяти и общих соображений о рынке.
3. **Допиши запись** в раздел «Разборы по ссылкам». Если раздела нет, создай его в конце файла заголовком `## Разборы по ссылкам`. Если конкурент уже есть в разделе (по названию или ссылке), обнови его запись, вторую не заводи.
4. **Покажи пользователю** коротко: что записано и какие поля «не установлено».

## Поля записи

Одинаковые у всех конкурентов, порядок и названия не менять:

```
### <Название> — <ссылка на сайт>
- Продукт: что делает, одной фразой.
- Задача: какую боль закрывает.
- Для кого: «цитата с сайта».
- Ключевые функции: список.
- Интеграции и платформы: веб, мобильное приложение, Telegram, с какими сервисами связан.
- Тарифы и цены: все тарифы, как на сайте.
- Бесплатный вход: триал, фримиум, бесплатный тариф и его лимиты.
- Обещание: «цитата с сайта» о том, какой результат обещают.
```

## Правила

- Цены как на сайте: своя валюта, все тарифы, без пересчёта.
- Цитаты в полях «Для кого» и «Обещание» дословные, в кавычках, с указанием страницы.
- Данных нет: пиши «не установлено» и почему (например, «тарифы на сайте не опубликованы»). Поле не выбрасывай, записи сравниваются построчно.
- Страница не открылась: так и напиши в записи («страница тарифов не открылась») и продолжай по остальным.
- Не выдумывай и не достраивай. Если сомневаешься, пиши «не установлено».
