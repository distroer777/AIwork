# Стек. Ярчинвест

| Слой | Технология | Обоснование |
|---|---|---|
| Frontend | TypeScript, Next.js, React, Tailwind | Обязательный минимум курса, один язык на весь проект |
| Backend | Next.js (Route Handlers, Server Actions) | Отдельный сервер не нужен, один репозиторий и один деплой |
| База данных | PostgreSQL, Prisma | Минимум курса, заменяет SQLite из нынешнего кабинета |
| Файловое хранилище | VK Cloud Object Storage (S3); локально MinIO в Docker | Видеоуроки, PDF, аватарки, файлы черновиков; сервер и хранилище в одном облаке, в коде один S3-клиент и разные переменные `S3_*` |
| Авторизация | Better Auth | Вход по email и паролю, подтверждение email кодом, работает с Prisma; роли ученик, куратор, админ добавим позже |
| Платежи | ЮKassa | Уже подключена в нынешнем кабинете, вебхуки и рассрочка |
| Почта | Brevo, RuSender | Brevo уже используется для писем кабинета; RuSender отправляет коды подтверждения |
| AI | OpenAI API через прокси | Переписывание постов; запросы идут через прокси-сервер, ключ только в `.env` |
| Инфраструктура | Docker, Dokploy на VK Cloud | Минимум курса, сервер уже есть; локально в Docker работает только база (`docker-compose.yml`) |
| Мониторинг | Логи контейнеров в Dokploy | Достаточно для старта |
