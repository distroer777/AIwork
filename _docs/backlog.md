# Бэклог. Ярчинвест

Идеи, баги и задачи, которые ещё не взяты в работу. Добавляй, обновляй и закрывай задачи здесь.

## Правила ведения

**Граница.** Бэклог: то, что ещё не взято в работу. Взятое в работу живёт в `_docs/features.md`. Одна и та же задача в двух файлах не лежит: взяли в работу, переносим в `features.md` и удаляем отсюда.

**Формат строки.** Одна строка = одна задача:

`- [ ] 🔴 область: короткое название`

- Статус: `- [ ]` открыта, `- [x]` сделана.
- Приоритет: 🔴 высокий · 🟡 средний · ⚪ низкий.
- Область (необязательно) через двоеточие перед названием: `feed:`, `auth:`, `ai:`, `landing:`.

**Секции.**
- `## Идеи`: что может пригодиться, пока не оценено.
- `## Баги`: что работает неправильно.
- `## Frontend`: задачи по интерфейсу.
- `## Backend`: задачи по серверу, базе, интеграциям.
- `## Готово`: закрытые задачи. Сделанную задачу переноси сюда и ставь `[x]`.
