# Дизайн-система. Ярчинвест

Значения токенов хранятся в `src/app/globals.css` (блок `@theme`). Здесь описано, какой токен для чего. Нужного значения нет: сначала заведи токен в `globals.css` и опиши его здесь, потом используй. Цвета и размеры в коде не пишем.

Стиль: светлый, спокойный, с одним синим акцентом. Тёмной темы нет.

## Цвета

| Токен | Класс Tailwind | Для чего |
|---|---|---|
| `--color-bg` | `bg-bg` | фон страницы и светлых секций |
| `--color-surface` | `bg-surface` | карточки, поля ввода, чередующиеся секции |
| `--color-ink` | `text-ink`, `bg-ink` | основной текст; фон подвала |
| `--color-ink-muted` | `text-ink-muted` | вторичный текст, подписи, описания |
| `--color-line` | `border-line` | границы карточек, полей, разделители |
| `--color-accent` | `bg-accent`, `text-accent`, `border-accent` | главные кнопки, акценты, выделенная карточка, финальный блок |
| `--color-accent-hover` | `hover:bg-accent-hover` | наведение на главную кнопку |
| `--color-accent-soft` | `bg-accent-soft` | мягкий фон: номера модулей, наведение на вторичную кнопку |
| `--color-on-accent` | `text-on-accent` | текст на акцентном фоне |
| `--color-on-ink` | `text-on-ink` | текст на тёмном фоне (подвал) |
| `--color-success` | `text-success` | сообщение об успехе |
| `--color-danger` | `text-danger` | сообщение об ошибке |

## Типографика

| Токен | Класс | Для чего |
|---|---|---|
| `--font-heading` (Unbounded) | `font-heading` | заголовки, цены, числа в карточках |
| `--font-sans` (Golos Text) | `font-sans` (по умолчанию на `body`) | весь остальной текст |

Размеры заголовков растут по ширине экрана: `text-2xl sm:text-3xl lg:text-4xl` для заголовков секций, `text-3xl sm:text-4xl lg:text-5xl` для главного заголовка.

## Скругления и тени

| Токен | Класс | Для чего |
|---|---|---|
| `--radius-card` | `rounded-card` | карточки и блоки |
| `--radius-control` | `rounded-control` | кнопки, поля ввода |
| `--radius-pill` | `rounded-pill` | маркеры, круглые номера |
| `--shadow-card` | `shadow-card` | тень карточек |

## Раскладка и адаптив

- Ширина содержимого: компонент `Container` (`max-w-6xl`, отступы `px-5 sm:px-8`).
- Вертикальные отступы секций: `py-14 sm:py-20`.
- Сетки: одна колонка на телефоне, `sm:`/`md:` две-три, `lg:` до четырёх.
- Брейкпоинты Tailwind: `sm` 640 px, `md` 768 px, `lg` 1024 px. Верстаем от телефона вверх (mobile first).
- Навигация в шапке скрыта до `lg`, ниже появляется кнопка-бургер с выпадающим меню.
- Карусель модулей прокручивается по горизонтали, на телефоне есть подсказка «Проведите по экрану».

## Компоненты

Каждый переиспользуемый элемент интерфейса лежит в `src/components/`. Клиентские (с состоянием) помечены.

| Файл | Что это |
|---|---|
| `container.tsx` | обёртка ширины и отступов |
| `section.tsx` | секция с подписью-эйбрау, заголовком и подзаголовком, тон `default` или `surface` |
| `button.tsx` | `ButtonLink`, варианты `primary` и `secondary` |
| `card.tsx` | карточка с необязательным заголовком |
| `stat.tsx` | число с подписью |
| `logic-card.tsx` | карточка «без системы» / «по системе» со списком |
| `cycle-steps.tsx` | шесть шагов цикла с возвратом к началу |
| `portfolio-widget.tsx` | виртуальный портфель: капитал, доходность, распределение |
| `program-tabs.tsx` (клиентский) | переключатель маршрутов и карусель модулей |
| `story-card.tsx` | карточка «было / стало» |
| `course-card.tsx` | карточка маршрута с ценой, доступом и кнопкой |
| `faq-item.tsx` | вопрос-ответ на `<details>` |
| `signup-form.tsx` (клиентский) | форма заявки: имя, уровень, способ связи, согласие |
| `site-header.tsx` (клиентский) | шапка с навигацией и мобильным меню |
| `site-footer.tsx` | подвал |

Новый элемент, которого здесь нет: создай компонент и добавь строку в эту таблицу.
