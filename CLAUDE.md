# Ярчинвест

## Что это за проект

Онлайн-обучение инвестициям «Ярчинвест» (yarchinvest.online): два курса по 8 модулей, «Начинающий инвестор» и «Практикующий инвестор». Ученик получает личный кабинет с видеоуроками, лекциями и домашними заданиями, живую работу с куратором один на один и виртуальный портфель для практики. Мобильные приложения нужны для удобства обучения, это не отдельный источник дохода.

- **ЦА.** Новички без опыта и люди с накоплениями на вкладах, которым страшно выходить на биржу. Для «Практикующего»: те, кто уже купил что-то по чужому совету и хочет разобраться сам.
- **Рынок.** Русскоязычный.
- **Отличие.** Нет комиссии со сделок учеников, обратная связь один на один, виртуальный портфель, договор с рассрочкой и без обещаний доходности.
- **Монетизация.** Разовая оплата за курс: «Начинающий» 20 000 ₽, «Практикующий» 35 000 ₽. Рассрочка на 2–3 месяца.

Этот проект учебный: копия для заданий курса, рабочий кабинет не переписываем.

- `_docs/competitors.md`: разбор конкурентов и рынка. Обращайся, чтобы понять, чем продукт отличается от существующих решений, как формулировать позиционирование и цену.
- `_docs/casdev.md`: вопросы для касдев-интервью с потенциальными пользователями.
- `_docs/mvp.md`: утверждённый состав первой версии. Функцию, которой нет в MVP, не делай «заодно».
- `_docs/features.md`: функционал итогового продукта, то есть что добавляется поверх MVP и какую боль закрывает.

- `_docs/design-system.md`: правила интерфейса, какой токен для чего. Читай перед созданием или правкой любого экрана, компонента или стиля.

Задавай уточняющие вопросы, если требуется.

## Стек технологий

TypeScript, Next.js, React, Tailwind, PostgreSQL с Prisma, VK Cloud Object Storage (S3), Better Auth, ЮKassa, Brevo и RuSender, OpenAI через прокси, Docker и Dokploy на VK Cloud. Подробности и обоснование: `_docs/stack.md`.

## Пользовательские правила

- Отвечай на русском и задавай уточняющие вопросы, если они нужны.
- Перед новой задачей сначала зафиксируй текущее состояние коммитом.
- Когда я подтвердил, что фича работает, предложи зафиксировать изменения коммитом с коротким описанием.
- Каждую фичу делай в отдельной ветке и вливай в main после проверки.
- Используй context7 mcp, когда нужно получить актуальную документацию по использованию внешнего инструмента.
- Каждый переиспользуемый UI-элемент выноси в отдельный компонент.
- Если не хватает информации по реализации функционала или исправлению бага, задавай уточняющие вопросы, пока не будет 100% понимания.
- Если не согласен с предложенной реализацией, аргументированно оспаривай и предлагай лучше.
- Когда создаёшь новый скилл или дорабатываешь существующий, сначала вызови скилл skill-creator и работай по его правилам.
- Стилизуем только токенами дизайн-системы, без цветов и размеров, вписанных прямо в код.
- Заводишь задачу в `_docs/features.md`: сначала проверь `_docs/backlog.md` и удали дубликат оттуда. Одна и та же задача в двух файлах не лежит.

## База данных (Docker)

База PostgreSQL работает в контейнере `yarchinvest-db` (файл `docker-compose.yml`). Приложение запускается локально через `npm run dev`, не в контейнере. Порт 5432 занят локальным Postgres, поэтому контейнер опубликован на порту из `DB_PORT` в `.env` (по умолчанию 5433), только на 127.0.0.1.

- Первый раз создай `.env`: `powershell -ExecutionPolicy Bypass -File _docs\setup-env.ps1` (пароли генерируются сами). Шаблон без значений: `.env.example`.
- Поднять базу: `docker compose up -d`. Проверить: `docker compose ps` (статус healthy).
- Остановить: `docker compose stop`. Остановить и удалить контейнер (данные сохраняются): `docker compose down`.
- Удалить вместе с данными: `docker compose down -v`. Делай только осознанно.
- Таблицы создаются командой `npx prisma migrate dev`.
- Файловое хранилище S3 локально работает в контейнере `yarchinvest-minio` (поднимается тем же `docker compose up -d`). Настройки хранилища дописывает в `.env` скрипт `_docs\add-s3-env.ps1`. Консоль MinIO: порт `S3_CONSOLE_PORT` из `.env`. В проде вместо MinIO VK Cloud Object Storage, меняются только переменные `S3_*`.
- Тексты юридических документов лежат в `_docs/legal` (версия и дата в шапке файла), реквизиты компании в `src/lib/company.ts`. При правке документа меняй `version` и `date`.
- Не коммить `.env`. Ключи (RuSender, OpenAI) хранятся только в `.env`.
